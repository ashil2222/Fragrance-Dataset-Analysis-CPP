# Fragrance Dataset Analysis System

A C++17 application developed for analyzing a fragrance dataset using CSV file processing and the Standard Template Library (STL).

## Features
- CSV dataset processing
- Fragrance searching
- Top 5 fragrance analysis
- Dataset analysis and reporting

## Technologies
- C++17
- Standard Template Library (STL)
- Visual Studio
- CSV file handling
